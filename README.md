# 投资组合监控中控台 · 个人实盘助手

个人实盘投资组合监控面板，还原「组合净值 K 线 / 当日盈亏瀑布 / 累计盈亏 / 基准对比 / 超额收益 / 持仓明细」全链路视图。

技术栈：**Next.js 14（App Router）+ TypeScript + SVG 图表（零图表库依赖）+ Postgres（可选）**，一键部署 Vercel。

## 功能

| 模块 | 说明 |
|---|---|
| 持仓概览 | 总资产 / 累计盈亏 / 持仓市值 / 今日总盈亏四卡；组合诊断（满仓度、最大回撤、胜率）；股息收益面板；K 线图、当日盈亏瀑布图、累计盈亏、三大基准卡、累计收益对比、超额收益曲线、持仓明细表 |
| 走势分析 | 区间收益、最大回撤、累计超额、胜率统计 + 三大走势图 |
| 重大事件 | 派息 / 异动 / 调仓 / 风险提醒时间线 |
| 财报追踪 | 持仓股业绩披露日历 |
| 交易记录 | 逐笔成交（方向 / 价格 / 数量 / 费用 / 备注） |

## 本地运行

```bash
npm install
npm run dev        # http://localhost:3000
```

未配置数据库时自动使用内置演示数据（截图快照，2026-10-23），界面完整可用。

## 部署到 Vercel

```bash
npm i -g vercel
vercel --prod
```

或在 [vercel.com](https://vercel.com) 导入 Git 仓库，框架选 Next.js，零配置部署。

### 线上部署状态

- 生产地址：<https://portfolio-console-eta.vercel.app>（2026-10-24 部署，状态 Ready）
- 仓库：<https://github.com/reakneel/portfolio-console>
- 说明：`*.vercel.app` 域名在部分网络环境（如中国大陆）可能无法直接访问，建议在 Vercel 项目设置中绑定自定义域名。

## 数据库（可选，适配 Vercel Postgres / Neon）

1. Vercel 项目 → **Storage** → 创建 **Postgres**（Neon），自动注入 `POSTGRES_URL`
2. 用 `db/schema.sql` 初始化表结构
3. 写入持仓后页面自动切换为数据库模式（页面底部标注数据来源）

本地调试：复制 `.env.example` 为 `.env.local` 并填入连接串。

### API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/portfolio` | 全量面板数据 |
| POST | `/api/holdings` | 新增 / 更新持仓（code/name/qty/costPrice/price…） |

## 数据口径

- **涨跌配色**：涨 / 正收益为红（#e53935），跌 / 负收益为蓝（#2196f3），遵循 A 股习惯
- **今日总盈亏**：13 只持仓当日盈亏之和（+5,209 元，含派息 +1,505 元口径已计入），与瀑布图逐笔加总一致
- **当日跑赢**：组合当日（+1.05%）− 基准当日；三个基准卡数字互洽（1.05−1.71=−0.66、1.05−0.89=+0.16、1.05−4.15=−3.10）
- **仓位**：个股市值 ÷ 总资产；13 只合计 86.3%（与满仓度一致）
- **累计盈亏**：持仓浮动盈亏 + 已清仓标的实现盈亏（贵州茅台 / 长城科技 / 红利低波100）
- **最大回撤（区间）**：由净值序列实际计算；「组合诊断」卡展示的 −29.5% 为账户成立以来历史最大回撤
- **净值 / 收益率序列**：演示快照下由确定性算法生成（seed=20261023，可复现），锚定截图 K 线形态与基准卡终点数值
